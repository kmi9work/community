# Афиша мероприятия: требуемый формат

Афиша — картинка в поле «Афиша (картинка) мероприятия» карточки мероприятия.
Одна и та же картинка уходит в анонсе мероприятия в Телеграм и MAX.

## Файл

| Параметр | Требование |
| --- | --- |
| Формат | JPEG или PNG; предпочтительно JPEG |
| Размер | 1080 × 1350 пикселей |
| Пропорции | 4:5, вертикальная |
| Вес | до 5 МБ |
| Цвет | sRGB |
| Имя файла | `(identifier типа)-(ГГГГ-ММ-ДД).jpg` — латиница, цифры, дефис |

Мессенджеры принимают файлы больше (Telegram — до 10 МБ, сумма ширины и высоты
до 10 000 пикселей, отношение сторон до 20), но 1080 × 1350 и 5 МБ достаточно:
картинка быстрее загружается и одинаково выглядит в обоих мессенджерах.

Исходник макета (PSD, Figma) хранится у администратора сообщества; в CRM
загружается только экспортированная картинка.

## Макет

```
+------------------------------------------+
| [лого]                                   |
|                                          |
|           НАЗВАНИЕ МЕРОПРИЯТИЯ           |
|                (≥ 72 px)                 |
|                                          |
|               иллюстрация                |
|                                          |
|          ДАТА · ВРЕМЯ (≥ 56 px)          |
|             МЕСТО (≥ 36 px)              |
|                                          |
+------------------------------------------+
    1080 × 1350, поля не меньше 64 px
```

Требования к композиции:

1. Поля не меньше 64 пикселей от каждого края; ключевой текст — не ближе
   96 пикселей от края.
2. Название мероприятия — в верхней половине, кегль не меньше 72 пикселей на
   ширине 1080.
3. Дата и время — одним блоком, кегль не меньше 56 пикселей.
4. Место — кегль не меньше 36 пикселей.
5. Не больше двух шрифтов.
6. Контраст текста и фона — не ниже 4.5:1.
7. Заголовок — не больше семи слов; остальное уходит в описание мероприятия.
8. Логотип сообщества — в левом верхнем углу, высота 80–120 пикселей.
9. QR-код — по желанию, не меньше 300 × 300 пикселей и с подписью.
10. В афише нет кнопок и элементов интерфейса мессенджеров, скриншотов и
    водяных знаков.

## Что обязательно на афише

1. Название мероприятия.
2. Дата и время.
3. Место: город и площадка; полный адрес — в описании мероприятия.

Тип мероприятия, иллюстрация и логотип — по желанию.

## Как используется

1. Анонс — одно сообщение: афиша и подпись. Подпись до 1024 символов в Телеграм
   и до 4000 в MAX; описание длиннее уходит отдельным сообщением.
2. Напоминания и сообщения о переносе или отмене уходят без афиши.
3. Бот не обрезает, не масштабирует и не накладывает текст на картинку —
   отправляет файл как есть.

## Проверка при загрузке

При сохранении админка проверяет формат, размер в пикселях и вес файла.
Неподходящий файл не сохраняется, причина показывается рядом с полем. Если на
афише напечатана дата, при переносе мероприятия картинку заменяют.

## Чего не делать

1. Растягивать готовый макет под 4:5 — макет пересобирается.
2. Класть текст на пёстрый фон без подложки.
3. Переносить в афишу программу, регламент и другой мелкий текст — это описание
   мероприятия.
