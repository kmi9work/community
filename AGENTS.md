## Подход к разработке
[в квадратных скобках задачи для ИИ]

Человеческое Описание проекта в файле ОПИСАНИЕ.md

1. Любые изменения, которые не соответствуют Человеческому Описанию - должны быть отдельно согласованы, согласованы правки в Человеческое Описание и только потом реализованы.
2. Правки в Человеческое Описание должны быть написаны так, как будто не было никаких изменений Описания. Не нужно обосновывать изменения в самом файле. Все обоснования - в чат.
2. Из Человеческого Описания строится файл "README.md" - техническое описание, в котором более детально описана система.
